# Hot-motor-swap thermal routing for a simulated hexapod

*Swapping Initial Motor Temperatures Changes Route Feasibility for a Simulated Hexapod* compares route selection using each motor’s initial temperature against selection using the mean and maximum temperatures. Both planners use the same execution controller. The evidence covers 288 MuJoCo walks across 72 starting scenarios.
