How the balancing works

The planner checks several distance/time/battery weight combinations using A*, removes candidates that lose in all three measures, then selects the lowest weighted score among energy-feasible choices. The score uses distance/50 m, time/90 s and energy/30%, multiplied by your normalized priorities. A smaller score wins. This is a sampled set of useful tradeoffs, not every possible road.
