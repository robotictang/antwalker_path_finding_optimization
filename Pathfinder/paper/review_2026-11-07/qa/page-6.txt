5.2 Parameter selection and repeated tests
Each of the four basic techniques is tested with two 
parameter  settings  on  the  development  maps.  The  
selection process begins by choosing the profile with  
the  highest  number  of  accepted  attempts  .  If  the  
acceptance counts are tied, the profile with the lesser  
average score of accepted attempts is selected. Exact  
ties  standard  profile  Each  basic  method  takes  the  
default  and  both  modified  CLRP  variants  use  that 
selection.
The other configuration of PSO-P uses 24 particles  
with inertia 0.55 and cognitive/social coefficients 1.7  
and 1.3. In the alternative configuration ACO-P uses  
18 ants, a heuristic exponent of 3 and an evaporation  
of 0.35. The other PSO-C configuration includes 20  
particles, 60 iterations, inertia = 0.75, cognitive and  
social coefficients = 1.6 and perturbation and velocity 
limit  =  4  m.  The  alternative  CLRP  profile  uses  
fractions of 0.55 for initial-search and 0.25 for extra-
point, 60 points, and local move dimensions of 0.50,  
0.15, and 0.05 m. All other configurations default to  
their previous values.
In  the  development  stage  there  are  64  planning 
tasks:  eight  maps,  four  methodologies  and  two  
profiles. The main test consists of 576 trials: 32 maps, 
6 techniques and 3 paired repetitions. Each technique  
includes  96  primary  test  attempts,  and  the  entire  
experiment consists of 640 attempts. The maps, the  
criteria for selecting the parameters, and the initial  
analysis were defined prior to the results of the main  
test. No external pre-registration. All planned primary 
examination work is included in acceptance totals.
All three runs on each map use the same geometry  
and  task  restrictions,  measuring  the  algorithmic  
variation on that particular map. They don't mean three 
separate maps. For paired comparison relative score  
differences, we first average within each map across  
mutually  agreed  repetitions,  and  then  we  average  
across maps. Therefore, each corresponding map is  
given equal importance regardless of the variation in  
the number of jointly recognised repetitions.

After the  main  test,  map-family  disaggregations,  
computational summaries, map-by-map visualisations 
and omission assessments were analysed. They report 
the  observed  results  without  altering  the  chosen
