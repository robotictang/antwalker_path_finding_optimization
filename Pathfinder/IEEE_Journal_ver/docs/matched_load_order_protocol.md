# Matched bank-order follow-up

Each of three new course templates has two successive two-branch stages. Each template is run with the negative bank stage first and with the positive bank stage first. Swapping the stages preserves the two sets of branch profiles, offsets, terrain parameters, total distance on the course axis, and deadline within that template. Physical loading is checked from nominal motor torques. Bank angle sign describes the geometry.

Cross both orders with the original slower-cooling and warmer-start thermal settings and their two mirrored initial temperature assignments. Compare the original two planners with the same 0.50 °C forecast margin, 2 s online search budget, speed options, and reactive controller. Each planner gets 24 starts. Complete the same continuous warm replay for identical schedules on the same start. Count every start in the denominator. These thermal settings were chosen following the earlier disagreements, so this is a mechanism study on fresh courses.

Check whether swapping the order, with initial temperatures held fixed, changes the available completion advantage from motor identities. Report completions, paired wins and losses, and the change in planner advantage by order for every template. Resample by template rather than treating the two orders as independent maps. Verify which side incurs greater nominal squared torque for the femur motors on each stage. Carry forward the original 10-percentage-point practical target for a general completion claim. This targeted suite cannot by itself establish a general advantage. The result may support a narrower claim about order and starting temperatures if effects are consistent across templates.

## Supplemental thermal settings

Both planners rejected every warm start in the first matched experiment. All nominal profiles completed. To obtain a completion comparison, a separate follow-up reused the identical nominal profiles and selected two thermal settings using the nominal forecasts. At a heating multiplier of 0.43, both planners forecast at least one admissible schedule for all 12 starts. At 0.44, the per-motor planner forecast at least one for 10 starts and the anonymous planner for four. These settings and the original decision rules were saved before running warm walks at either new setting. Both use 120 s cooling and the original 67/45 °C temperature pair. This separates the new warm executions from the admission sweep used to choose their settings. The estimates are conditional on a deliberately selected thermal range.
