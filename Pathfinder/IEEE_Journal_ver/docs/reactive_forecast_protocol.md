# Forecasting reactive slowdown before route selection

The [disagreement audit](discordant_replays.md) found that changing commanded speed after planning can change both thermal stops and completion. This follow-up tests whether planning for that feedback improves completion on different simulated courses.

The [configuration](../experiments/reactive_forecast.json) fixes four new maps, three actuator settings drawn from the previous studies, and both assignments of the same warm motors. It carries forward the 0.50 °C planning margin, 70 °C execution stop, two-second online search budget, and 10-percentage-point practical target. Both speeds must complete in the isolated nominal branch profiles for that branch to enter the common candidate set. All planners know which motors start warm. Every execution uses the same thermal derating and reactive controller.

1. The existing forecast stitches standalone profiles at their scheduled speeds.
2. The second forecast builds branch profiles over forward position, interpolates nominal speeds, and includes only the first stand.
3. The third forecast adds the execution controller's trigger, hysteresis, and speed ramp to the second forecast. When reactive and planned speed differ, the lower command drives the forecast.

The position-based forecasts use per-motor mean squared torque and forward progress rates measured at the two available commands. The nominal walk is binned at roughly 0.30 m and advanced in 0.50 s steps. The last bin supplies the remaining distance to an intermediate junction because standalone walks terminate within the goal radius. A continuous warm replay may move or load its motors differently from either nominal crawl. The position model does not predict per-step gait, contact changes, or the resulting effect of torque derating. The temperature estimate may continue past the limit so it can screen the full planned distance. Offline profiling and model construction are outside the online budget for all planners.

Each method selects the admissible schedule with the lowest predicted peak, breaking ties by predicted finish time and schedule name. The main outcome is paired completion of the reactive forecast versus the existing forecast. The second forecast isolates the effect of modeling slowdown. All selected schedules plus one fastest nominal probe per start are replayed. The probes apply the same execution protections even if a planner rejected the schedule. Every predictor also scores that common replay set. Compare admission against observed outcomes and compare peak-temperature and timing errors over completed replays. Because the replay set comes from these planners plus fastest probes, its screening metrics describe this sample of schedules. The map-resampled interval is descriptive with four maps.
