# Transferring calibrated temperature and deadline margins

The [reactive-forecast comparison](reactive_forecast.md) found smaller forecast errors with the slowdown controller modeled, but fewer mission completions at the inherited 0.50 °C margin. This experiment asks whether recalibrating admission for this forecast recovers completed walks on fresh courses.

Use only the 34 archived reactive replays for calibration. Each archive item combines a full-schedule forecast with its observed completion, thermal stop, or deadline miss. A thermal stop truncates the walk, so calibration uses the observed outcome and the full-schedule forecast.

For every pair on the [fixed grid](../experiments/reactive_margin_transfer.json), admit a schedule only if its peak forecast is strictly below the stop temperature minus the temperature margin and its predicted finish time is at or before the deadline minus the time margin. Require that every development thermal stop fail the temperature gate by itself. Also require that no failed development replay pass both gates. Among eligible pairs, choose the one admitting the most observed finishes. Break ties with the larger temperature margin, then the larger time margin. Record leave-one-course-out screening on the development set to show sensitivity to course selection. This diagnostic never changes the chosen margins.

Freeze the selected pair, all calibration results, and the course definitions before running any warm missions on the six new maps. Compare the calibrated planner with the same reactive forecast using 0.50 °C and 0 s of headroom. Also run the earlier stitched planner at its inherited margin as a reference. All three know the same starting motor temperatures, rank admitted schedules by forecast peak and then finish time, and use the same controller, physical deadline, thermal stop, two-second online budget, and candidate branches. A branch needs completed nominal profiles at both speeds to be available to any planner.

The primary criterion is a gain of at least 10 percentage points in goal completion relative to the fixed reactive forecast with no increase in observed thermal stops. Count planning rejections, timeouts, and failed walks in each method's denominator. Report the paired course-resampled interval as descriptive. Replay the union of chosen schedules plus the fastest nominal schedule for each start, sharing identical physics runs. Screen this common replay set with both reactive margin policies. Probe outcomes help reveal admission errors even if a method's chosen routes finish.

These empirical margins describe the constructed course sample and simulated actuator and controller. The development sample includes only one deadline miss, so timing-margin transfer has limited support.
