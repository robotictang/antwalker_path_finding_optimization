Use Python 3.10 or a compatible supported version in an isolated environment. Install requirements-pinned.txt. From reproduction/mujoco run:
python3 -m research.extension_study --directory outputs/research/reproduction_v5

This writes a new campaign. It does not overwrite archived results. Fixed wall-clock budgets mean routes and selected profiles can vary on different machines. The relocation log distinguishes asset-path edits from unchanged archived scientific sources. See source/analysis_plan.json for analysis rules. To reproduce manuscript analysis, install NumPy and Matplotlib and run source/analyze_extension.py; it reads evidence/validation_extension_v5. Run source/analyze_original_v4.py to recompute the original study analysis. To rebuild the Word manuscript, install python-docx and lxml and run source/build_manuscript.py. The retained official Word template is included. render_paper.py is a task-host QA wrapper with local runtime paths; use a compatible Word/PDF renderer on another machine.
